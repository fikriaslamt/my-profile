# Taste

- Wants site content (profile, projects, experience, socials, etc.) kept in typed data files under a content directory so text can be edited without touching components; no custom backend, frontend/static only. Confidence: 0.8
- On multi-phase builds, wants a checkpoint after each phase: run build + lint, post screenshots in light & dark and desktop & mobile, then summarize in ≤5 lines before continuing. Confidence: 0.7
- Values "done" over exhaustive polish: when something already works, stop adding tests/refinements and wrap up rather than continuing to iterate. Confidence: 0.6
- When drawing inspiration from a reference site, reproduce only structure/UX patterns — never copy its text, photos, logos, or other assets. Confidence: 0.6
